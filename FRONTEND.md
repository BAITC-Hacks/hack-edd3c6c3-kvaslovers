# Career Quest frontend

Запуск: `python3 -m Backend.main` из корня, затем http://127.0.0.1:8000.
Отдельный сервер статики не нужен. Интерфейс использует относительные API URL,
cookie-сессии и CSRF-токен. Профили, история, прогресс и HR-метрики приходят
с сервера. При ошибке API выводится ошибка; демонстрационные данные не подставляются.

Есть вход, регистрация по приглашению, карточки рекомендаций с коротким и полным
объяснением, раскрытие навыков/истории, выполнение, поиск HR и импорт четырёх файлов.
Интерфейс на русском. EN/KZ-локализация в финальную сборку не включена.

Контракт: [README](README.md). Проверка синтаксиса: `node --check app.js`.
