# Проверка обязательных требований Career Quest

Источник: раздел «КЕЙС: CAREER QUEST» пользовательского PDF HackAlem AI,
русская версия, страницы 3–6. Проверка: 2026-09-23, дата данных 2026-10-01.
Границы: обязательные пункты и ограничения. Перечисленные в ТЗ опциональные
награды, календарь, прогноз оттока и другие расширения не заявляются готовыми.

## Итоговые автоматические проверки

`python3 -m unittest discover -v`: **32 теста, OK**, 3.902 с в итоговом прогоне после изменений приглашений.
`node --check app.js`: OK. `git diff --check`: OK.
`python3 -m ai.demo --output ai/demo`: три исходных сценария воспроизводятся.

Дополнительно на локальном HTTP-сервере с отдельной SQLite-базой проверены
вход E0002, выполнение EV_005 и повторное получение профиля (**62% → 66%**),
вход HR, сводка и импорт трёх профилей/трёх строк истории. Отдельно проверена
регистрация: публичный список возвращает 401, присвоение ID без приглашения —
403, HR-токен регистрирует только связанный профиль и после использования
отклоняется.

Проверяется конкретная локальная конфигурация с kit из 200 профилей,
не гарантируется задержка для произвольного оборудования и размера импорта.
Ожидания инструментов браузера и их проверок разрешений не являются временем
ответа приложения.

## Ручная проверка браузера

- Вход сотрудника: виден собственный профиль, нет HR и выбора чужих профилей.
- Вход HR: доступен выбор сотрудников, все HR-сводки и импорт.
- Импортирован новый JURY_UI с тремя строками no_show; профиль появился в выборе.
- Импортированный профиль получил Designing High-Load Systems, System Design
  Fundamentals и Architecture Review Circle.
- После выполнения следующей активности покрытие изменилось **12% → 16%**;
  перезагрузка страницы сохранила **16%**.
- Открыта пустая выдача после исчерпания доступных шагов.
- Кнопка локальной LLM без модели вернула явный deterministic fallback.
- Проверена узкая ширина встроенного браузера: элементы доступны, таблицы
  прокручиваются в своём контейнере. Отдельного полного аудита доступности не было.

Файловый диалог встроенного браузера недоступен инструменту автоматизации;
импорт через вставку JSON/CSV проверен полностью. Файловый путь использует
стандартный input[type=file] и тот же проверенный API.

## Что не следует заявлять на защите

- Алгоритм не обучен на бизнес-результатах; веса — объяснимая эвристика.
- Локальная LLM интегрирована по HTTP, но не установлена на этой машине.
  Успешный ответ, транспортный формат, ошибка и deadline проверены тестами;
  живой вывод настоящей модели не проверен. Без неё работает алгоритм по правилам.
- Синтетический учебный стенд не является production банковской системой:
  нет корпоративного SSO, TLS-терминации и внешнего развёртывания.
- Выполнение — симуляция на фиксированной дате kit, а не подтверждение
  реального присутствия на будущей сессии.
- Доля покрытия навыков не является вероятностью или гарантией повышения.
- Профили жюри ещё неизвестны; проверены дополнительные собственные профили
  той же схемы, а не скрытый оценочный набор организаторов.

## Данные и внешние сервисы

Исходные данные остаются в локальном приложении/командном репозитории хакатона.
Сервер выдаёт только разрешённый конкретному пользователю API, а не каталоги
файлов. Секреты и БД исключены из Git. LLM-адаптер ограничен localhost,
облачные отправки не выполняются. Исходные файлы kit сохранены без изменений.
