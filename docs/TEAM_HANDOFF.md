# Финальная сборка команды

Объединены защищённый backend из `codex/backend-integration` и ветка
`codex/frontend-fixes`. Конфликты решены в пользу единого API с cookie и CSRF.
Интерфейс адаптирован: поиск, раскрытие навыков/истории и серверные метрики.
Старые маршруты, подстановка demo-данных, история в localStorage и второй сервер
статики исключены. Единственный исходный kit находится в `ai/data`.

Для сдачи используйте `main`. Команды запуска и проверки — в корневом README.
Не переносите поверх финальной сборки старые app.js или Backend/main.py целиком.
