# Передача команде

Ветка `ai` теперь содержит связанное веб-приложение, а не только рекомендатель.
Запуск из корня: `python3 -m Backend.main`. Тесты: `python3 -m unittest discover -v`.

Во время реализации ветки команды обновились параллельно:

- `back` на момент сверки: `561cf4a`;
- `front` на момент сверки: `364764c`;
- `main` на момент сверки: `e84caa8` (файлы интерфейса перенесены из main в front).

Собранная версия в `ai` использует оформление исходного frontend и исходный
движок; backend, API и UI доведены совместно. Она запускается самостоятельно.
Параллельные ветки не являются проверенной сборкой с этим новым API.

Для ознакомления без слияния своей работы создайте отдельную рабочую копию:

```bash
git fetch origin
git worktree add ../career-quest-integrated origin/ai
cd ../career-quest-integrated
python3 -m Backend.main
```

Если порт занят, используйте `--port 8001`. Пароли генерируются отдельно в
`.local/credentials.json` этой копии.

При последующем объединении согласуйте API из корневого README:

- Требуются cookie-сессия и CSRF для изменений. Удалять авторизацию ради
  совместимости старой страницы нельзя: разграничение доступа требуется ТЗ.
- Frontend и API обслуживаются с одного адреса; wildcard CORS не нужен.
- `/api/employees` возвращает массив кратких профилей, не `{employees: [...]}`.
- Рекомендации — массив; `/api/employees/{id}` включает его в `recommendations`.
- Выполнение: POST `/api/employees/{id}/complete`, тело `{event_id}`.
- Прогресс: `trajectory.progress_pct`; навыки: `level`, `required`, `gap`.
- HR-сводка: `employee_count`, `skill_gaps`, `no_next_step`,
  `inactive_90_days`, `participation`.
- Нет подстановки демонстрационных HR-значений при ошибке API: показывается ошибка.

Данные прогресса находятся в новой SQLite-схеме. Автоматическая миграция базы
из параллельной реализации `back` не выполнялась; не указывайте её файл в `--db`.
Исходный kit одинаков по смыслу, но путь по умолчанию здесь — `ai/data`.

Нужно совместно пройти: вход сотрудника → рекомендация → выполнение → новый
прогресс; вход HR → импорт нового профиля → рекомендации → HR-сводка.
Матрица проверки находится в `docs/ACCEPTANCE.md`.
