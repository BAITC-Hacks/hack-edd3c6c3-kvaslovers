# Career Quest backend

Запуск из корня: `python3 -m Backend.main` (Python 3.9+, стандартная библиотека).
HTTP API и интерфейс работают на одном адресе http://127.0.0.1:8000.
Параметры: `--host`, `--port`, `--db`. Данные: `ai/data`; состояние: `.local`.
Учётные записи и пароли создаются локально; сотрудник видит только свой профиль.
Регистрация сотрудника требует одноразового приглашения HR.

Полный контракт API, импорт и ограничения: [README](../README.md).
Проверки: `python3 -m unittest discover -v`.
